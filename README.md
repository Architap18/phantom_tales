# 👻 Phantom Tales

An AI-powered horror story generator that creates spooky, personalized stories based on your imagination.

### ✨ Features
- AI-generated horror stories using Groq API
- Custom locations and main characters
- Three fear levels: Mild, Moderate, and High
- Copy stories with one click
- Responsive, horror-themed UI

### 🛠️ Tech Stack
React, Vite, JavaScript, Node.js, Express.js, Groq API, and Vercel.

### 🚀 Live Demo
[Phantom Tales](https://phantomtales.vercel.app)

### 💻 Run Locally
1. Clone the repository.
2. Install dependencies in `frontend` and `backend`.
3. Configure `GROQ_API_KEY`, `GROQ_MODEL`, and `VITE_API_URL` in your environment files.
4. Start the backend and frontend servers.
